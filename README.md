# Model PBR Shader 基于物理的模型渲染

Download 下载: [Releases](https://github.com/XiaofengdiZhu/ModelPbrShaderForSC/releases)

This is a mod for [Survivalcraft API](https://gitee.com/SC-SPM/SurvivalcraftApi)  
After installing this mod, the game will have full support for glTF models. And it provides physically based rendering (PBR) for all the creature models, with dynamic image based lighting (IBL).  
It requires a device that supports OpenGL ES 3.2. If you cannot enter the game world, or the creature models are not rendering properly, please disable/uninstall this mod.

这是一个适用于[生存战争插件版](https://gitee.com/SC-SPM/SurvivalcraftApi)的模组  
用于支持 glTF 模型的全部功能，并为所有生物模型提供基于物理的渲染（PBR），附动态的基于图像的光照（IBL）  
需要设备支持 OpenGL ES 3.2，如果安装该模组后无法进入存档，或生物模型渲染异常，请禁用/卸载此模组
